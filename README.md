# Код поколения

Пять командных игр для младших школьников и наставников: родной край, взаимопомощь, местная история и полезные школьные дела.

Проект использует символику БРСМ и БРПО как тематический ориентир и остаётся самостоятельной разработкой, не официальным сайтом организаций.

## Сайт

Публичная страница: [https://arsenmay.github.io/brsm-kod-pokoleniya/](https://arsenmay.github.io/brsm-kod-pokoleniya/)

Исходный код: [arsenmay/brsm-kod-pokoleniya](https://github.com/arsenmay/brsm-kod-pokoleniya)

Сайт публикуется через GitHub Pages из корня ветки main. Репозиторий открыт, посетителям сайта аккаунт GitHub не нужен.

## Автономная версия

`Kod_pokoleniya_offline.html` — отдельный файл со встроенным кодом, стилями и изображениями. Его можно открыть локально на компьютере без интернета. На телефонах открытие локальных HTML-файлов зависит от браузера.

## Состав проекта

- `index.html` — основная страница приложения.
- `styles.css` — оформление и печатные стили.
- `data.js` — сценарии, роли и ключи заданий.
- `app.js` — переходы, проверки головоломок, таймер и материалы ведущего.
- `assets/` — иллюстрация и эмблемы.

Игра не собирает данные игроков, не требует входа и не использует серверный код, внешние библиотеки или шрифты.

## Атрибуция

Символика БРПО: [официальный сайт](https://brpo.by/). Эмблема БРСМ: [официальная страница символики](https://brsm.by/ru/simvolika-ru/). Иллюстрация команды создана специально для проекта и не является официальной символикой. Проект независимый и не заявляет об официальном одобрении БРПО или БРСМ.

Рекомендуемая конкурсная номинация по предоставленному положению — «Шефский десант». Перед апробацией педагог должен проверить соответствие заданиям и возрасту своей группы.
