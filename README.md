# Код поколения

Пять командных игр для младших школьников и наставников: родной край, взаимопомощь, местная история и полезные школьные дела.

## GitHub Pages

1. Создайте **публичный** репозиторий с именем `kod-pokoleniya` в аккаунте `arsenmay`.
2. Загрузите содержимое этой папки в корень ветки `main`, включая скрытый файл `.nojekyll`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**, branch `main`, folder `/(root)`, затем нажмите **Save**.
5. После успешной сборки страница будет доступна по адресу `https://arsenmay.github.io/kod-pokoleniya/`.

Публикация может занять несколько минут. Если адрес не открылся сразу, проверьте статус Pages в Settings → Pages.

В аккаунте GitHub Free Pages доступны из публичных репозиториев. Перед созданием проверьте видимость: код проекта и изображения станут общедоступными вместе с сайтом. Личные данные и секреты в этот комплект не включены.

## Автономная версия

`Kod_pokoleniya_offline.html` — отдельный файл со встроенным кодом, стилями и изображениями. Его можно открыть локально на компьютере без интернета. На телефонах открытие локальных HTML-файлов зависит от браузера.

## Состав проекта

- `index.html` — основная страница приложения.
- `styles.css` — оформление и печатные стили.
- `data.js` — сценарии, роли и ключи заданий.
- `app.js` — переходы, проверки головоломок, таймер и материалы ведущего.
- `assets/` — иллюстрация и эмблемы.
- `.nojekyll` — отключает обработку Jekyll для статических файлов.

Игра не собирает данные игроков, не требует входа и не использует серверный код, внешние библиотеки или шрифты.
